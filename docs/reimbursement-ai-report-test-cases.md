# 报销单 AI 报表查询联调测试用例

## 1. 文档目的

本文档用于支撑前后端联调、后端接口测试和 AI 报表降级验证。

使用数据：

- [reimbursement-production-export.mock.json](/Users/zhouhao/Documents/AI_APP/03-AICFO/data/reimbursement-production-export.mock.json)

---

## 2. 基础说明

当前 mock 数据共 5 条，来自生产系统导出 Excel 转换结果。

已知样本特征：

- 事由主要为“东/西校区 + 月份 + 水费”
- 时间覆盖：2026 年 1 月至 3 月
- 状态均为“已通过”
- 合计金额：`58,104`

因此当前样例最适合验证：

- 基础汇总指标
- 月度趋势图
- 校区维度对比图
- AI 解读生成

---

## 3. 测试环境建议

- 前端使用当前 mock JSON 驱动页面
- 后端在无数据库环境下，可直接使用该 JSON 做本地重算验证
- GraphQL 层可先 mock 固定返回，再接入真实服务

---

## 4. 核心联调用例

### 用例 1：正常返回推荐图表

#### 输入

- 查询条件：全部命中当前 mock 数据

#### 预期

- 返回 `summaryMetrics`
- 返回至少 1 张推荐图表
- 返回 AI 解读
- `traceInfo.fallback = false`

#### 关键断言

- `summaryMetrics[0].value = "5 笔"`
- `summaryMetrics[1].value = "58,104 元"`
- `recommendedChartId` 存在于 `availableCharts`

---

### 用例 2：推荐时间趋势图

#### 输入

- 查询条件：`keyword = 水费`
- 时间范围：`2026-01-01 ~ 2026-03-31`

#### 预期

- 推荐图表倾向为 `line` 或 `bar`
- 分组维度为时间相关维度
- 图表标题应与“月度趋势/对比”语义一致

#### 可接受结果

- `dimension = apply_date_month`
- `metric = sum(amount)`

---

### 用例 3：Java 重算金额一致性

#### 输入

使用 mock 数据全量记录重算按月金额。

#### 预期

按月总额应为：

- 1月：`25,326`
- 2月：`29,544`
- 3月：`3,234`

#### 断言

- 图表所有月度金额和 = `58,104`

---

### 用例 4：Java 重算校区对比

#### 输入

由事由中可识别：

- `东校区`
- `西校区`

#### 预期

按校区累计金额应为：

- 东校区：`35,328`
- 西校区：`22,776`

#### 断言

- 校区图表分项之和 = `58,104`

---

### 用例 5：基础指标优先返回

#### 输入

- LLM 正常或异常均可

#### 预期

后端始终优先返回：

- 报销单笔数
- 报销总金额

即使图表失败，基础指标也必须存在。

---

## 5. 降级测试用例

### 用例 6：LLM 超时

#### 模拟方式

- 人工让模型接口超时
- 或通过 mock 强制返回 timeout

#### 预期

- 后端返回 `200`
- 使用降级图表
- `insight.source = rule_fallback`
- `traceInfo.fallback = true`

---

### 用例 7：LLM 输出非法 JSON

#### 模拟方式

- 返回非 JSON
- 返回字段缺失

#### 预期

- 后端不报 500
- 自动切换到降级逻辑

---

### 用例 8：LLM 输出非法维度

#### 模拟方式

模型返回：

```json
{
  "recommendedChart": {
    "chartType": "pie",
    "dimension": "campus",
    "metric": "sum(amount)"
  }
}
```

#### 预期

- 若 `campus` 不在白名单，后端拒绝直接使用
- 回退到可重算维度

---

## 6. 前端联调检查项

前端联调时重点检查：

- 右侧抽屉是否能稳定渲染
- 基础指标是否固定展示
- 图表切换是否正常
- AI 解读是否超长、换行异常
- 降级态是否仍可展示
- 空数据时是否有空态

---

## 7. 空数据测试

### 用例 9：无命中结果

#### 输入

- 查询条件无匹配记录

#### 预期

- `summaryMetrics` 返回：
  - `0 笔`
  - `0 元`
- `availableCharts` 可为空或返回空图
- `insight.summary` 为提示性文案
- 前端展示空态，不应报错

---

## 8. 安全测试

### 用例 10：敏感字段不外发

#### 检查项

模型输入中不应包含：

- 银行账号
- 开户行
- 非必要支付敏感信息

#### 预期

- Prompt 构造层能严格裁剪字段

---

## 9. 性能测试建议

### 用例 11：常规请求性能

#### 目标

- 基础指标：`< 100ms`
- AI 报表总时长：`< 4s`

### 用例 12：LLM 慢响应

#### 目标

- 超过超时阈值时自动降级
- 不阻塞前端长期 loading

---

## 10. 验收标准

达到以下条件可认为第一阶段完成：

- 前端可稳定展示基础指标 + 推荐图表 + AI 解读
- 后端能基于全部命中结果返回标准协议
- LLM 输出经过 Java 重算与校验
- 异常时能稳定降级
- 前后端联调无需再修改字段协议
