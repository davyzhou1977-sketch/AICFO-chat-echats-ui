# AICFO 根仓库迁移方案

## 目标

将 AICFO 的多端研发逐步收敛到一个统一根仓库中，避免：

- Web 与移动端分散管理
- 文档、设计规范、数据样例多处重复
- 需求联动时上下文割裂

## 当前现状

- 根目录 [03-AICFO](/Users/zhouhao/Documents/AI_APP/03-AICFO) 已初始化为新的 Git 仓库
- 当前工作区中的 [reimburse-list-chat-echarts](/Users/zhouhao/Documents/AI_APP/03-AICFO/reimburse-list-chat-echarts) 仍是独立 Web 仓库
- 为避免扰动现有协作，根仓库当前先忽略该独立 Web 仓库

## 迁移原则

1. 不影响当前 Web 同事已有协作
2. 先稳定根仓库，再择机迁移 Web
3. 迁移前先统一目录结构
4. 迁移时只动一次，不反复折腾

## 推荐迁移路径

### 阶段 1：根仓库启动

- 初始化根仓库
- 整理移动端代码与文档
- 固化设计规范、接口契约和数据样例

### 阶段 2：规划标准目录

建议目标目录：

```text
apps/
  web/
  mobile/
docs/
Data/
shared/
```

### 阶段 3：Web 迁移窗口

在 Web 同事确认窗口后：

1. 从独立 Web 仓库导出稳定版本
2. 放入根仓库的 `apps/web`
3. 校验构建、环境变量、部署路径
4. 再统一切到根仓库协作

### 阶段 4：统一协作

- Web 与移动端都在根仓库开发
- 共享文档、规范、数据样例统一维护

## 当前建议

当前不要立即改造独立 Web 仓库，先继续：

- 使用根仓库推进移动端演示与正式开发
- 保持 Web 仓库独立协作
- 等前端同事看完当前移动端版本后，再约一个时间做 Web 迁移
